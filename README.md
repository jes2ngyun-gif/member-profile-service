# Member Profile Service

## 프로젝트 소개

Spring Boot와 AWS를 활용하여 팀원 정보를 관리하고 프로필 이미지를 업로드하는 백엔드 서비스를 구현하는 프로젝트입니다.

## 프로젝트 목표

- 팀원 정보 등록 및 조회 API 구현
- AWS 기반 인프라 구축
- Stateless 아키텍처 구성
- EC2, RDS, S3를 활용한 서비스 운영
- Docker 및 CI/CD 적용

## 기술 스택

- Java 17
- Spring Boot 4.0.7
- Spring Web
- Spring Data JPA
- Validation
- H2 Database
- MySQL
- Spring Boot Actuator
- AWS
